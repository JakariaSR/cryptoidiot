"Smart contract" is the most misleading name in crypto. It isn't smart, and in most places it isn't legally a contract — it's **a program that runs on a blockchain, exactly as written, with no one able to stop or alter it.** That one idea is why Ethereum exists, where most [DeFi](what-is-defi.html) comes from, and why billions of dollars have also vanished into buggy code. Worth understanding properly.

## The definition in one breath

A smart contract is code stored on the blockchain. Anyone can send it a transaction — "lend me money," "swap these tokens," "buy this NFT" — and the code executes the rules automatically. No company runs it. No employee can freeze it. No lawyer needs to enforce it, because **the enforcement is the execution.** The code *is* the agreement.

Nick Szabo coined the term in the 1990s with a perfect analogy: a vending machine. You put in money, press a button, and the machine *mechanically* delivers the snack. No cashier, no trust, no "sorry, out of stock" negotiation — the machine either works as built or it doesn't. A smart contract is a vending machine for anything that can be expressed in code and paid in crypto.

## What they're actually for

Nearly everything interesting in crypto beyond plain money transfers is a smart contract:

- **Decentralized exchanges** — swapping tokens without a company in the middle (the software half of [CEX vs DEX](cex-vs-dex.html))
- **Lending and borrowing** — deposit collateral, borrow automatically, no bank manager
- **New tokens** — most [altcoins](what-is-an-altcoin.html) are literally smart contracts on Ethereum or similar chains, which is why anyone can launch one
- **NFTs and digital ownership** — the deed to a digital item, enforced by code
- **Staking rewards** — the logic that pays [staking](what-is-staking.html) yield without a payroll department

One reason [Ethereum](what-is-ethereum.html) matters so much is that it was the first network to make smart contracts its main product — a general-purpose world computer instead of a single-purpose money ledger.

## The superpower: composability

Here's the quietly revolutionary part. Because smart contracts are public and follow shared standards, **any new contract can plug into every existing one** — like Lego bricks. A savings app can automatically route your deposit through three other protocols to find the best yield, without asking anyone's permission.

Traditional finance calls this "integration" and spends years on it. In crypto it's the default, and it's the real engine behind how quickly the ecosystem builds (and how quickly risk spreads — the same plumbing that composes profits composes failures).

## The catch, stated honestly

**The code runs exactly as written — including the bugs.** There's no admin to call, no fraud department, and (usually) no undo. If a contract has a flaw, attackers will find it, because the code is public and the money it holds is real. Billions of dollars have been lost to smart contract exploits, and "the code was audited" — while genuinely useful — is a risk reduction, not a guarantee. The deeper pattern from [rug pulls](what-is-a-rug-pull.html) and [common crypto scams](common-crypto-scams.html) applies here too: *where the money lives, sophisticated attacks follow.*

Which is why the practical rules for a beginner are simple: use long-established, heavily-used contracts for anything serious; treat brand-new protocols offering dazzling yields as experiments, not savings accounts; and remember that "no one can stop it" cuts both ways — no one can stop it from paying you, and no one can stop it from being drained.

## The one-paragraph version

A smart contract is a program stored on a blockchain that executes its rules automatically for anyone who interacts with it — no company, employee, or court needed, because execution and enforcement are the same thing. They're the foundation of everything beyond simple transfers: decentralized exchanges, lending, new tokens, NFTs, and staking rewards, all able to plug into each other like Lego bricks — a property called composability that makes the ecosystem build fast. But they run exactly as written, bugs included, with no undo button, which is why exploits have cost billions and why beginners should favor old, battle-tested contracts over shiny new high-yield ones. "Smart" describes the mechanism; whether any given contract is smart to use is still on you.
