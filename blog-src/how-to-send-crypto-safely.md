Moving crypto from one place to another — exchange to wallet, wallet to wallet — is the moment every beginner's hands start sweating. And honestly? Good. **A crypto transaction is final.** There's no fraud department, no undo button, no bank manager who can reverse it. The good news: the disasters almost all come from a short list of preventable mistakes. Here's the full checklist that prevents them.

## Rule zero: the test transaction

This one rule eliminates almost all the risk in this entire guide:

> **Send a small test amount first. Confirm it arrives. Then send the rest.**

Ten dollars of caution before a four-figure transfer. It costs one extra network fee and a few minutes. Every experienced crypto user does this for any new address or new wallet, every time, no matter how confident they are. Make it an unbreakable habit.

## Check the address like your money depends on it (it does)

Crypto addresses are long strings of random characters — exactly the kind of thing humans are terrible at. So don't rely on eyeballing:

- **Copy and paste, then visually check the first AND last several characters** — malware exists that swaps copied addresses (the clipboard-swapper is one of the oldest crypto trojans).
- **Better: use the QR code** when both devices are present.
- **Never type an address by hand.** Just don't.

One reassurance for a common fear: addresses include built-in checksums, so a *typo* usually fails loudly instead of sending to a stranger. The real dangers are copy-swap malware, pasting the wrong coin's address, and pasting an address belonging to a different network entirely.

## Pick the right network — the #1 way beginners lose money

This is the single most common costly mistake, so read it twice: **an address isn't just an address — the network matters.**

The same coin can exist on multiple networks. USDC, for example, lives as an Ethereum token, a Solana token, a Tron token, and more — each with different addresses and fees. Every transfer must send **on a network the receiving side supports**. Send Ethereum-network USDC to a Tron-only address and the funds can be permanently lost, even though you pasted a "valid" address.

The rule: **on the sending screen, select the exact network the receiving wallet or exchange tells you to** — they always display it ("Receive USDC via Ethereum/ERC-20," for instance). When in doubt, use the network the receiver's "deposit" page specifies, and remember this is also where [gas fees](what-is-gas-fee.html) differ wildly — network choice is a cost decision too.

## Match the coin to the address, every time

- Bitcoin → a Bitcoin address (starts with `1`, `3`, or `bc1`)
- Ethereum and its tokens → an Ethereum address (starts with `0x`)
- Every other coin/network → its own format

Sending Bitcoin to an Ethereum address (or vice versa) usually fails safely — but "usually" isn't "always," and some cross-chain mistakes are unrecoverable. The receiving wallet's deposit page exists precisely to tell you what it accepts; use it.

## The rest of the safety stack

- **Small test first.** Already said. It's that important.
- **Double-check on the device.** If you use a hardware wallet, verify the address on the device's own screen, not just the computer's — that's the whole point of the device ([what a hardware wallet](what-is-a-hardware-wallet.html) explains why).
- **Beware the "send me crypto" messages.** Anyone DMing you an address — prize, giveaway, "support," Elon-adjacent generosity — is running the classics from [common crypto scams](common-crypto-scams.html). Legitimate recipients never rush you.
- **Note the fees before confirming.** Exchanges add withdrawal fees on top of network fees; big ones are worth [cashing out through a different route entirely](how-to-cash-out-crypto.html) if the amount is small.

## If it goes wrong

Sent to the wrong address with no response? Contact the receiving exchange's support immediately if it was their deposit address — *sometimes* they can help, for a fee, if the mistake was recoverable on their end. Sent to a wallet you control but on the wrong network? Wallets can often add a custom network to reach stranded tokens. Sent to a random person's address? Almost certainly unrecoverable — which is why every habit above exists.

## The one-paragraph version

Crypto transfers are irreversible, so safety is a checklist, not a vibe: send a small test amount to any new address first; copy addresses and verify the first and last characters against the destination (watch for clipboard-swap malware); select the exact network the receiver's deposit page specifies, since the same coin can exist on many networks and a network mismatch can permanently strand funds; match coin type to address format; verify on your hardware wallet's own screen if you have one; and treat anyone rushing you into sending funds as a scam until proven otherwise. Follow those and the terrifying moment becomes a boring one — which is the entire goal.
